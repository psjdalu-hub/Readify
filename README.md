Readify
Readify is a simple frontend project that 
represents a book reading platform UI.

Features:- Clean and simple user interface
         - Basic navigation between pages
         - Book display layout

Technologies Used:- HTML
                  - CSS
                  - JavaScript

About the Project:-
      This project was created to practice 
      frontend development skills, including 
      layout design, styling, and basic interactivity.
